# Python-Event-Loop-Async-and-Blocking
This repository explains the basics of synchronous and asynchronous programming in Python.


Topics Covered :.

1.Synchronous Programming: Executes tasks sequentially.

2.Asynchronous Programming: Allows other tasks to run while a task is waiting.

3.Event Loop: Manages and schedules asynchronous tasks.

4.Blocking Operations: Prevent the event loop from running other tasks on the same thread.

5.asyncio.sleep() vs time.sleep(): Understand the difference between non-blocking and blocking waits.

* Purpose

-To understand how Python handles multiple tasks using async programming and how blocking operations affect the event loop.
