# Python-Event-Loop-Async-and-Blocking
This repository explains the basics of synchronous and asynchronous programming in Python.


Topics Covered

Synchronous Programming: Executes tasks sequentially.

Asynchronous Programming: Allows other tasks to run while a task is waiting.

Event Loop: Manages and schedules asynchronous tasks.

Blocking Operations: Prevent the event loop from running other tasks on the same thread.

asyncio.sleep() vs time.sleep(): Understand the difference between non-blocking and blocking waits.

Purpose

To understand how Python handles multiple tasks using async programming and how blocking operations affect the event loop.
